# Plans

Calibre's active plans live in the project's OKF bundle:

`$OBSIDIAN_VAULT_PATH/Projects/Calibre/plans/`

Terminal `shipped` and `failed` plans move to the bundle's
`archive/plans/`; explicit handoffs remain active. Start at
`Projects/Calibre/index.md`, then read only the plan relevant to the current work.

This directory is a **public-safe redirector**: it names *where* the plans live,
never a plan body. New plans are written to the vault; if the vault is
unreachable a skill may write a temporary local plan here, then relocate it to
the vault on return. In fallback mode, terminal plans move to
`docs/archive/plans/`. See AGENTS.md → *Agent memory* and
`docs/agents/domain.md`.
